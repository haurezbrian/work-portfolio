# Carnova

A travel-discovery and trip-planning application with request intake connected to backend services and notifications.

**My role:** Full-stack development  
**Stack:** Web frontend, NestJS/Fastify services and PostgreSQL

## What I built

- Travel-discovery and multi-service trip-planning interfaces.
- Request-submission flows connected to persistent backend records.
- Protected operations and notification processing.
- API, worker and database integration supporting a request-based deployment.

## Engineering focus

The application carries a visitor's selections from the planning interface into a stored request and notification workflow. This required coordination across frontend state, API behaviour, persistence and email relay.

My work also included investigating form-state behaviour and the deployment steps connecting local changes to the hosted application.

**Demonstrated capabilities:** Connected application workflows, backend integration, request persistence, notifications and deployment troubleshooting.
