# Reusable Project Foundation

A repeatable starting point for application development, with project profiles, container configuration and operating documentation.

**Technology:** Node.js, Docker Compose and GitHub Actions

## What the foundation provides

- Minimal, web, API, full-stack and CMS project profiles.
- Runtime templates and documented operating commands.
- Verification scripts and CI configuration.
- Localhost port-allocation checks.
- Registry locking and atomic updates.

## Engineering focus

The initializer handles project setup as a repeatable operation. Port checks address conflicts between local projects, while locking and atomic updates protect shared registry changes.

The operating documentation connects the generated files to the commands needed to start, inspect and maintain the project environment.

**Demonstrated capabilities:** Developer tooling, container-based setup, automation, configuration management and technical documentation.
